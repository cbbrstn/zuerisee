How this works: All ZSG boats serving the main lake routes depart from and return to Zürich Bürkliplatz (See). The Utoquai–Seebad Enge axis lies ~4 minutes travel from Bürkliplatz, so every departure crosses the axis outbound ~4 min after leaving, and every arrival crosses it ~4 min before docking. Both departure and arrival stationboards are queried from transport.opendata.ch.

RED = boat crosses within this 15-min window.   YELLOW = boat within ±5 min of the window edge (delay buffer).   GREEN = clear.   Hover chips for scheduled vs prognosis times. Open the debug log to inspect raw API results.
